The cognitive overlay, in CSS terms

The game's interface is not a HUD skin — it is Vann's cognitive overlay, drawn as chamfered navy panels over a signal-blue grid. This page states the visual system as design tokens and CSS, exactly as it ships. Both are vendored from the game itself — tokens.css from UiThemeTokens, components.css from VindicatorWebStyle — and every demo below is the shipped class, not a copy of it.

Color tokens

Six base tokens carry the whole interface. Everything else is derived by mixing or fading them.

--bg-deep#060B12Deep navy-black substrate. Space itself.
--panel-base#0E1826Panel glass fill.
--signal#83C3FFPrimary structure: rails, headers, hover, grid.
--cassius#F59A56CASSIUS external comms. Nothing else.
--fold#91A6FFExotic tech: the fold drive.
--online#05C6C1Online, success, pressed.
--nav-ink#D0D0D0Body, data, resting button labels.
--steel-rail#B5CBE0mix(nav-ink, signal 35%) — resting button rail.

Derived tokens are alpha fades of the base set:

--rail:       rgba(131, 195, 255, 0.55);  /* signal @ 55% — the 1px outline everywhere */
--grid-major: rgba(131, 195, 255, 0.11);  /* signal @ 11% — 64px grid lines */
--grid-minor: rgba(131, 195, 255, 0.05);  /* signal @ 5%  — 16px grid lines */
--muted-ink:  rgba(208, 208, 208, 0.50);  /* nav-ink @ 50% — footnotes, version tags */
--steel-rail: #B5CBE0;  /* color-mix(in srgb, var(--nav-ink) 65%, var(--signal)) */

Color semantics — four voices

  • SIGNAL CYAN — the overlay's own voice. Structure, rails, headers, anything active or hovered.
  • ONLINE GREEN — confirmation. Systems online, success, credits, a pressed button.
  • CASSIUS ORANGE — reserved. Only CASSIUS speaks in orange, so the companion can annotate the interface without appearing to own it.
  • FOLD PERIWINKLE — exotic. Marks fold-drive tech and nothing mundane.

The reservation rule is the point: a color that can mean anything means nothing. Orange on this screen is always someone talking to you from outside.

Shape — chamfer, never radius

Every surface cuts its corners at 45°. There is no border-radius anywhere in the language — on the web the cut is a clip-path octagon:

clip-path: polygon(
  var(--c) 0,  100% 0,
  100% calc(100% - var(--c)),  calc(100% - var(--c)) 100%,
  0 100%,  0 var(--c)
);

The cut size is per surface class:

PANEL 14px
TOOLTIP 10px
BUTTON 8px
CHIP 6px

Around every cut runs a 1px rail (--rail, signal @ 55%). In-game ChamferStyleBox strokes the whole octagon, diagonals included; on the web only nesting can do that, so the language splits by construction: panels close the octagon — a clipped .vframe whose 1px of padding lets its rail-colored background show around a clipped .vpanel child — while buttons and chips leave the corners open, since a single element's border is cut away by its own clip-path at the four 45° segments. At 6–8px cuts on a 1px rail the gap is invisible; at panel scale it is not, which is why panels pay for the extra element.

Panel anatomy

SELECTION

This panel is the live recipe, straight out of components.css: a rail frame around a flat panel-base face, with a static signal glow thrown outside the cut.

Three layers, outside in:

  1. Glow — drop-shadow(0 0 7px …) at signal @ 40% on the frame, so the halo follows the chamfered silhouette instead of a rectangle. The game's breathing shader is the engine twin; on the web it holds still.
  2. Rail — the frame's own background, revealed as 1px by its padding: --rail by default, --cassius under .vframe.cassius, --signal when the frame is a link under the pointer.
  3. Fill — flat --panel-base. No gradient, no top highlight, no scanlines: the quiet pass retired all three in-game, and the site follows so one look ships everywhere.

Panels sit on a signal-tinted grid substrate — 16px minor lines at 5%, every fourth line (64px) major at 11%:

One decorative motion is allowed: a slow additive signal-tinted shimmer band travelling top to bottom (~20s per pass, 10% alpha). It never strobes, it opts in per surface, and the landing hero is the only place this site takes it.

Buttons

Play / Wishlist

Two shapes, one pair of jobs. The secondary .vbtn (hover it) is a steel hairline over the grid tint; the primary .vbtn.go drops the rail entirely and floods the accent, so commitment reads as fill rather than as a louder outline:

StateRailFillLabel
.vbtn rest--steel-rail--grid-minor--nav-ink
.vbtn hover--signal--grid-majorwhite
.vbtn.gonone--online--bg-deep, 600

The resting rail is deliberately desaturated steel — mix(nav-ink, signal 35%) — so the cyan hover reads as a clear step up. Both wear a 7px cut with open corners, and both are sans: the quiet pass reserved mono for data, and a button label is chrome. Pages may set padding and font-size for their own scale (the landing hero does) and nothing else.

.vbtn {
  border: 1px solid var(--steel-rail);
  color: var(--nav-ink);
  background: var(--grid-minor);
  clip-path: polygon(7px 0, 100% 0, 100% calc(100% - 7px),
                     calc(100% - 7px) 100%, 0 100%, 0 7px);
}
.vbtn:hover { border-color: var(--signal); color: #fff; background: var(--grid-major); }
.vbtn.go    { border: none; background: var(--online); color: var(--bg-deep); font-weight: 600; }

Chips

SYS // VINDICATOR CREDITS 4,210 CASSIUS // EXTERNAL

Chips are the smallest surface and the only chrome still written in mono — a chip is a piece of data wearing a box. One 6px cut (--chamfer-chip-sm), 12px caps at 2px letter-spacing, an accent rail at 90% and the same accent mixed 10% into panel navy for the fill. No scanlines: noise at that size. The accent is the chip's one decision, taken with the .online / .cassius modifiers and following the voice rules above — a chip never mints its own color.

Provenance

Authoritative source is the game code: common/UiThemeTokens.cs (tokens, size ladder, state tables) and common/ChamferStyleBox.cs (the chamfered draw model). The Godot theme resource vindicator_theme.tres is only an editor preview mirror — it is normalized from these tokens at startup. The two stylesheets this page loads are generated from that code and vendored here by build_docs.cs, byte-identical to what the in-game state server serves; vindicator.css adds layout and nothing else. A chrome look the components cannot give grows a knob in VindicatorWebStyle and re-vendors — the site cannot fork a recipe, which is what let this page drift a full design pass behind the game the last time it owned its own panels.
